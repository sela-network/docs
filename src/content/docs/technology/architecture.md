## The Three-Layer Stack

### 계층별 역할

| 계층                                  | 역할                               | 핵심 기술                                       |
| ------------------------------------- | ---------------------------------- | ----------------------------------------------- |
| **L1: Web Transport Layer**           | 분산 브라우저 실행, 웹 페이지 접근 | dBrowser Nodes, Residential Proxy               |
| **L2: Semantic Interpretation Layer** | HTML/화면 → JSON/Action 변환       | VLM, DOM-to-JSON Engine, Self-Healing Selectors |
| **L3: Verifiability Layer**           | 데이터 무결성 증명, 출처 인증      | zk-TLS, Notary Signatures                       |

## 상세 아키텍처

### Layer 1: Web Transport Layer (웹 전송 계층)

**목적**: AI 에이전트에게 안전하고 확장 가능한 웹 접근 제공

**구성 요소:**

1. **dBrowser Nodes (분산 브라우저 노드)**

   - 전 세계 분산된 실제 브라우저 인스턴스
   - 크롬 확장 프로그램 또는 독립 실행형
   - 지역별 최적 노드 자동 선택

2. **Residential Proxy Network**

   - 실제 주거용 IP 주소 활용
   - Bot 탐지 시스템 우회
   - 지역 제한 콘텐츠 접근

3. **Session Manager**
   - 로그인 세션 관리
   - 쿠키 및 인증 상태 유지
   - 멀티 세션 격리

**주요 기능:**

- ✅ 인간 브라우징 패턴 모방
- ✅ WebGL, Canvas, AudioContext 지문 생성
- ✅ 동적 JavaScript 렌더링
- ✅ 파일 업로드/다운로드 처리

---

### Layer 2: Semantic Interpretation Layer (의미 해석 계층)

**목적**: 시각적 웹 콘텐츠를 AI가 이해하는 구조화된 데이터로 변환

**구성 요소:**

1. **Vision Language Model (VLM)**

   - UI 요소의 시각적 인식
   - 버튼, 입력 필드, 메뉴 등 자동 탐지
   - 레이아웃 및 계층 구조 이해

2. **DOM-to-JSON Engine**

   - HTML DOM을 JSON 스키마로 변환
   - 의미론적 태그 추출
   - 구조화된 데이터 생성

3. **Self-Healing Selector System**

   - UI 변경 자동 감지
   - CSS Selector 자동 업데이트
   - 파서 안정성 유지

4. **Schema Normalizer**
   - 동일 URL에 대한 일관된 스키마 보장
   - AI 에이전트 호환성 극대화
   - 버전 관리 및 스키마 진화

**처리 플로우:**

```
HTML/CSS/JS 페이지
    ↓
VLM 시각 분석 + DOM 파싱
    ↓
의미론적 요소 추출
    ↓
JSON 스키마 생성
    ↓
Schema 정규화
    ↓
AI Agent로 전달
```

---

### Layer 3: Verifiability Layer (검증 가능성 계층)

**목적**: 웹 데이터의 무결성과 출처를 암호학적으로 증명

**구성 요소:**

1. **zk-TLS (Zero-Knowledge Transport Layer Security)**

   - TLS 핸드셰이크 정보의 ZK Proof 생성
   - 데이터가 실제 서버에서 왔음을 증명
   - 민감 정보는 ZK 방식으로 보호

2. **Notary Service**

   - 독립적인 제3자 검증
   - 타임스탬프 및 서명
   - 감사 추적(Audit Trail)

3. **Proof Aggregation**
   - 여러 증명을 효율적으로 결합
   - 온체인 검증 최적화
   - 스토리지 비용 절감

**검증 가능한 요소:**

- ✅ 데이터 출처 (어느 서버에서 왔는가)
- ✅ 데이터 무결성 (조작되지 않았는가)
- ✅ 시간 증명 (언제 데이터를 받았는가)
- ✅ 경로 증명 (어떤 경로로 데이터가 왔는가)

## 확장성 및 성능

### 수평적 확장 (Horizontal Scaling)

- **노드 추가**: 누구나 노드를 추가하여 네트워크 확장
- **지역별 분산**: 가까운 노드 자동 선택으로 레이턴시 최소화
- **로드 밸런싱**: 스마트 라우팅으로 부하 분산

### 성능 최적화

- **캐싱 레이어**: 자주 요청되는 페이지 캐싱
- **병렬 처리**: 여러 요청 동시 처리
- **스마트 프리페칭**: 예상 요청 미리 처리

### 보안

- **격리된 실행**: 각 요청은 독립적인 샌드박스에서 실행
- **암호화 통신**: 모든 데이터 전송은 암호화
- **접근 제어**: 토큰 기반 권한 관리

---

이 3계층 아키텍처는 **확장성**, **보안성**, **검증 가능성**을 모두 달성하며, AI 에이전트 시대의 웹 인프라 표준이 됩니다.
