## 1. Sela Node (dBrowser Node)

전 세계 사용자 또는 사업자가 운영하는 **분산 브라우저 인프라**입니다.

### 주요 특징

#### Fingerprint Mimicking (지문 모방)

실제 인간 브라우징 패턴을 완벽하게 재현합니다.

**모방 요소:**

- 🖱️ **WebGL**: GPU 렌더링 특성
- 🎨 **Canvas**: 그래픽 렌더링 고유값
- 🔊 **AudioContext**: 오디오 처리 특성
- ⚙️ **User Agent**: 브라우저 및 OS 정보
- 🖥️ **Screen Resolution**: 화면 해상도 및 픽셀 밀도
- ⏱️ **Timing Patterns**: 마우스 움직임, 타이핑 속도

**결과:**

- ✅ Cloudflare, Akamai, Datadome 등 Bot 탐지 우회
- ✅ 실제 사용자와 구별 불가능한 트래픽
- ✅ 안정적인 웹사이트 접근

#### Isolation Sandbox (격리 샌드박스)

노드는 사용자의 민감한 정보에 접근할 수 없습니다.

**보안 기능:**

- 🔒 쿠키 및 세션 정보 격리
- 🔒 로컬 스토리지 분리
- 🔒 계정 정보 보호
- 🔒 독립된 실행 환경

#### Geo-Distributed Execution (지역 분산 실행)

지역별로 최적화된 노드 선택으로 정확도를 극대화합니다.

**지역별 최적화:**

```
한국 데이터 요청 → 한국 노드 실행
미국 데이터 요청 → 미국 노드 실행
일본 데이터 요청 → 일본 노드 실행
```

**이점:**

- 🌏 지역 제한 콘텐츠 접근
- ⚡ 낮은 레이턴시
- 🎯 정확한 지역 맞춤 콘텐츠
- 💰 CDN 비용 절감

#### Action Automation (액션 자동화)

복잡한 웹 인터랙션을 완벽하게 자동화합니다.

**지원 액션:**

- 🖱️ 클릭 (Click)
- 📜 스크롤 (Scroll)
- ⌨️ 텍스트 입력 (Type)
- 📥 파일 다운로드 (Download)
- 📤 파일 업로드 (Upload)
- 🔄 드래그 앤 드롭 (Drag & Drop)
- ⏸️ 대기 (Wait)
- 🔍 요소 검색 (Find Element)

## 2. Semantic Rendering Engine (SRE)

HTML 파싱을 넘어 UI의 **"의도(semantic)"**를 읽는 엔진입니다.

### Hybrid Parsing (하이브리드 파싱)

Vision과 DOM 파싱을 결합한 차세대 파싱 기술입니다.

#### Vision-Based Parsing (시각 기반 파싱)

**로컬 VLM (Vision Language Model) 내장:**

- 👁️ 버튼 위치 인식
- 🎨 색상 및 스타일 인식
- 📝 레이블 텍스트 인식
- 📐 레이아웃 구조 이해

#### DOM-Based Parsing (DOM 기반 파싱)

**구조적 의미 추출:**

- 📊 HTML 태그 계층 구조
- 🏷️ 시맨틱 태그 (header, nav, article 등)
- 🔗 링크 및 참조 관계
- 📋 폼 및 입력 필드

#### 결합 효과

```
Vision Parser    +    DOM Parser
     ↓                    ↓
  버튼 위치 인식      버튼 기능 파악
     ↓                    ↓
         통합 분석
             ↓
    완벽한 의미 추출
```

### Self-Healing Selector Engine

UI 구조가 변경되어도 자동으로 파서를 복구합니다.

#### 동작 원리

1. **초기 매핑**: 첫 방문 시 UI 요소 매핑
2. **변경 감지**: UI 구조 변경 자동 감지
3. **재매핑**: 새로운 구조로 자동 업데이트
4. **검증**: 정확도 확인 및 최적화

#### 실제 예시

**쿠팡 UI 변경 시:**

```
변경 전: button.buy-button
변경 후: button.purchase-btn

→ Self-Healing Engine 작동
→ 자동으로 새 Selector 탐지
→ 서비스 중단 없이 계속 작동
```

#### 지원 사이트

- ✅ 쿠팡 (Coupang)
- ✅ 아마존 (Amazon)
- ✅ 네이버 (Naver)
- ✅ 쿠팡이츠, 배달의민족 등 모든 주요 사이트

### Schema Normalization (스키마 정규화)

동일 URL 요청 시 항상 동일한 JSON 스키마를 제공합니다.

#### 정규화 규칙

**일관성 보장:**

```json
// 항상 동일한 구조
{
  "product": {
    "name": "string",
    "price": "number",
    "currency": "string",
    "availability": "boolean",
    "images": ["string"]
  }
}
```

**AI 에이전트 안정성 확보:**

- ✅ 예측 가능한 데이터 구조
- ✅ 에러 처리 간소화
- ✅ 빠른 통합
- ✅ 유지보수 부담 감소

## 3. zk-TLS: Verifiable Web Proof Layer

Sela의 가장 핵심적인 차별점입니다.

### 개요

AI가 받은 데이터가 **진짜 웹 서버에서 온 것임을 증명**합니다.

### 핵심 기술

#### TLS Handshake ZK Proof

**프로세스:**

1. 브라우저와 서버 간 TLS 핸드셰이크
2. 핸드셰이크 정보를 ZK Proof로 압축
3. 데이터 출처 및 무결성 증명 생성
4. 온체인 또는 오프체인 검증

**증명 내용:**

- ✅ 서버 인증서 검증
- ✅ 데이터 무결성
- ✅ 타임스탬프
- ✅ 전송 경로

#### Zero-Knowledge 프라이버시

**민감 정보 보호:**

- 🔒 실제 데이터는 노출하지 않음
- 🔒 증명만으로 검증 가능
- 🔒 사용자 프라이버시 완벽 보호

### 사용 사례

#### 금융 데이터

**예시: 은행 잔고 조회**

```
증명 내용:
- ✅ 데이터 출처: 실제 은행 서버
- ✅ 조회 시간: 2024-01-15 10:30:00
- ✅ 데이터 무결성: 조작되지 않음
- 🔒 실제 잔고 금액: Zero-Knowledge로 보호
```

#### 뉴스 및 정보

**예시: 블룸버그 뉴스 기사**

```
증명:
"이 뉴스 기사 페이지가 실제 블룸버그 서버에서
도착한 본문임"을 AI가 직접 증명 가능
```

#### 법률 및 컴플라이언스

**예시: 정부 규제 문서**

```
- 문서 출처 증명
- 다운로드 시점 증명
- 변조 여부 검증
- 감사 추적 가능
```

### 기술적 이점

| 항목             | 기존 방식    | zk-TLS            |
| ---------------- | ------------ | ----------------- |
| 데이터 출처 증명 | ❌ 불가능    | ✅ 가능           |
| 조작 방지        | ❌ 취약      | ✅ 강력           |
| 프라이버시       | ❌ 노출 위험 | ✅ Zero-Knowledge |
| 법적 효력        | ❌ 없음      | ✅ 암호학적 증명  |
| 감사 가능성      | ❌ 제한적    | ✅ 완벽한 추적    |

## 기술 통합 효과

### 시너지 효과

```
Sela Node (접근)
    +
SRE (이해)
    +
zk-TLS (증명)
    =
완벽한 AI 웹 에이전트
```

### 실제 워크플로우 예시

**"아마존에서 에어팟 최저가 검색 후 주문"**

1. **Sela Node**: 아마존 접속 (Bot 탐지 우회)
2. **SRE**: 상품 목록을 JSON으로 변환
3. **zk-TLS**: 가격 데이터 출처 증명
4. **AI Agent**: 최저가 상품 선택
5. **Sela Node**: 장바구니 추가 및 결제 페이지 이동
6. **zk-TLS**: 주문 내역 증명 생성
7. **완료**: 검증 가능한 주문 완료

---

이 세 가지 핵심 기술의 완벽한 결합으로 Sela Network는 AI 에이전트가 웹에서 **안전하게**, **효율적으로**, **검증 가능하게** 작동할 수 있는 환경을 제공합니다.
