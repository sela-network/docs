## 설계 철학

### 핵심 원칙

1. **기여도 기반 보상**

   - 실제 네트워크 기여에 비례한 보상
   - 품질과 성과 중심 평가

2. **장기적 인센티브**

   - 단기 투기보다 장기 참여 장려
   - 베스팅(Vesting) 메커니즘 적용

3. **투명성**

   - 모든 보상 온체인 기록
   - 누구나 검증 가능

4. **지속 가능성**
   - 네트워크 성장과 함께 보상 증가
   - 선순환 구조

## 보상 분배 메커니즘

### 자동 분배

**블록체인 기반:**

- 스마트 컨트랙트 자동 실행
- 사람 개입 없는 공정한 분배
- 투명한 기록

### 주기

| 보상 유형   | 분배 주기 | 방식 |
| ----------- | --------- | ---- |
| API 수수료  | 실시간    | 자동 |
| 기본 보상   | 매 블록   | 자동 |
| 성능 보너스 | 주간      | 자동 |
| Grant       | 마일스톤  | 수동 |

## 수수료 구조

### API 사용 수수료

**기본 구조:**

```
요청당 비용: 시장 수요에 따라 변동

예상 범위: 0.001 - 0.1 SELA

수수료 배분:
├─ 70% → 노드 운영자
├─ 20% → 프로토콜 재무
└─ 10% → 소각 (Burn)
```

**변동 요인:**

- 네트워크 혼잡도
- 요청 복잡도 (VLM, zk-TLS 등)
- 노드 지역

## 슬래싱 (Slashing)

### 패널티 시스템

**목적:**

- 악의적 행위 방지
- 서비스 품질 유지

**대상:**

```
심각: 데이터 조작, 거짓 증명 → 스테이킹 전액 몰수
중간: 저품질 서비스 → 일부 감액
경미: 일시적 다운타임 → 경고
```

## 생태계 펀드

### Treasury 관리

**수입:**

- 프로토콜 수수료 (20%)
- 마켓플레이스 수수료
- 파트너십 수익

**사용:**

```
40% → Grant 프로그램
30% → 마케팅 및 성장
20% → R&D
10% → 비상 준비금
```

**거버넌스:**

- 커뮤니티 투표로 결정
- 투명한 지출 기록

## 시작하기

### 노드 운영자가 되려면

1. 최소 100 SELA 스테이킹
2. 노드 소프트웨어 설치
3. 네트워크 참여 시작

### 개발자로 참여하려면

1. 개발자 계정 생성
2. SDK 다운로드
3. 파서/스크립트 개발 시작

### 사용자로 시작하려면

1. 회원가입
2. API Key 발급
3. 포인트 적립 시작

## 보상 계산 예시

### 노드 운영자 (예시)

```
스테이킹: 1,000 SELA
월 요청 처리: 10,000건
평균 수수료: 0.01 SELA
성능 등급: A (+20%)

월 예상 수익:
  수수료: 10,000 × 0.01 × 0.7 = 70 SELA
  보너스: 70 × 0.20 = 14 SELA
  총: 84 SELA

* 실제 수익은 시장 조건에 따라 변동
```

### 개발자 (예시)

```
파서 판매:
  가격: 20 SELA
  월 판매: 10건
  개발자 몫: 70%

월 수익: 10 × 20 × 0.7 = 140 SELA
```

**주의:** 모든 수치는 예시이며 실제와 다를 수 있습니다.

## FAQ

**Q: 보상은 언제 받나요?**
A: 보상 유형에 따라 다릅니다. API 수수료는 실시간, 기본 보상은 매 블록, 보너스는 주간 단위입니다.

**Q: 최소 스테이킹은 얼마인가요?**
A: 노드 운영 시 최소 100 SELA가 필요합니다.

**Q: 수익을 예측할 수 있나요?**
A: 네트워크 사용량과 토큰 가격에 따라 변동되므로 정확한 예측은 어렵습니다.

**Q: 세금은 어떻게 되나요?**
A: 각 국가의 세법을 확인하시기 바랍니다. Sela Network는 세무 자문을 제공하지 않습니다.
