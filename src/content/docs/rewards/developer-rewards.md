## 마켓플레이스 수익

### 파서 (Parser) 판매

**개념:**

- 특정 웹사이트용 데이터 추출 도구 개발
- 마켓플레이스에 등록하여 판매
- 지속적인 수동 수익 창출

**수익 배분:**

```
판매 가격의 70% → 개발자
판매 가격의 20% → 프로토콜
판매 가격의 10% → 큐레이터/검증자
```

**가격 책정 가이드:**
| 복잡도 | 권장 가격 | 예시 |
|--------|----------|------|
| 단순 | 5-10 SELA | 단일 페이지 파싱 |
| 중급 | 10-30 SELA | 다중 페이지, 페이지네이션 |
| 고급 | 30-100 SELA | 복잡한 SPA, 동적 콘텐츠 |
| 엔터프라이즈 | 100+ SELA | 대규모 스크래핑, 유지보수 포함 |

---

### Automation Scripts

**개념:**

- 복잡한 웹 작업 자동화 워크플로우
- 여러 단계를 포함하는 시나리오 패키지

**수익 모델:**

1. **일회성 구매**

   - 개발자: 70%
   - 프로토콜: 30%

2. **구독 모델** (월정액)
   - 개발자: 75%
   - 프로토콜: 25%

**인기 카테고리:**

- 이커머스 자동화
- 소셜 미디어 관리
- 데이터 수집 파이프라인
- 모니터링 및 알림

---

### Data API 서비스

**개념:**

- 수집한 데이터를 API로 제공
- 실시간 또는 주기적 데이터 공급

**수익 배분:**

```
API 호출당: 개발자 80%, 프로토콜 20%
월 구독: 개발자 75%, 프로토콜 25%
```

## Grant 프로그램

### 혁신 Grant

**대상:**

- 새로운 기술 도입
- 생태계 확장에 기여
- 오픈소스 도구 개발

**지원 범위:**

```
소규모: 1,000-5,000 SELA
중규모: 5,000-20,000 SELA
대규모: 20,000-50,000 SELA
```

**선정 기준:**

- 기술적 혁신성 (40%)
- 생태계 기여도 (30%)
- 실행 가능성 (20%)
- 팀 역량 (10%)

---

### 버그 바운티

**범위:**
| 심각도 | 설명 | 보상 |
|--------|------|------|
| Critical | 자금 손실, 네트워크 중단 | 1,000-10,000 SELA |
| High | 데이터 유출, 권한 상승 | 500-1,000 SELA |
| Medium | 서비스 품질 저하 | 100-500 SELA |
| Low | 사소한 버그 | 50-100 SELA |

**제출 방법:**

1. GitHub Issues
2. 전용 이메일: security@sela.network
3. HackerOne (출시 후)

## 오픈소스 기여 보상

**보상 기준:**

- 테스트 커버리지

**예상 보상:**

```

Major PR (기능 추가): 200-1,000 SELA
Critical PR (보안, 성능): 1,000-5,000 SELA
```

- 기술 문서 작성
- 튜토리얼 제작
- 번역 작업
- 비디오 가이드

**보상:**

```
문서 작성: 100-500 SELA
튜토리얼: 200-1,000 SELA
번역 (주요 언어): 500-2,000 SELA
비디오 가이드: 1,000-5,000 SELA
```

## 신청 프로세스

### Grant 신청

1. **제안서 제출**

   - 프로젝트 개요
   - 기술 사양
   - 예산 계획
   - 타임라인

2. **심사** (2-4주)

   - 기술 팀 검토
   - 커뮤니티 피드백

3. **승인 시**
   - 계약 체결
   - 초기 자금 (30%)
   - 마일스톤 기반 지급

---

### 마켓플레이스 등록

1. **개발**

   - 파서/스크립트 개발
   - 테스트

2. **제출**

   - 코드 업로드
   - 문서 작성
   - 가격 설정

3. **검증** (1-2주)

   - 코드 리뷰
   - 보안 검사
   - 품질 확인

4. **승인**
   - 마켓플레이스 등록
   - 수익 발생

## FAQ

**Q: Grant를 받으면 소스코드를 공개해야 하나요?**
A: 프로젝트 성격에 따라 다릅니다. 오픈소스를 권장하지만 필수는 아닙니다.

**Q: 마켓플레이스 수수료는 왜 있나요?**
A: 플랫폼 운영, 검증, 마케팅 비용을 충당하기 위함입니다.

**Q: 외국인도 신청 가능한가요?**
A: 네, 전 세계 누구나 신청 가능합니다.
