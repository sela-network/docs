## 토큰 경제학 (Tokenomics)

### 공급 & 수요 역학

#### 수요 증가 요인

1. **네트워크 사용 증가**

   ```
   AI Agent 시장 성장 (CAGR 40%)
   → API 호출 증가
   → SELA 수요 증가
   ```

2. **노드 운영자 증가**

   ```
   고수익률 (APY 200-400%)
   → 더 많은 노드 참여
   → 스테이킹 수요 증가
   ```

3. **마켓플레이스 성장**
   ```
   개발자 생태계 확대
   → 파서/스크립트 거래 증가
   → SELA 결제 수요 증가
   ```

#### 공급 감소 요인

1. **스테이킹 락업**

   ```
   40-60%의 SELA가 스테이킹
   → 유통 공급량 감소
   ```

2. **지속적 소각**

   ```
   연간 1-5% 소각
   → 총 공급량 감소
   → 디플레이션 압력
   ```

3. **베스팅 스케줄**
   ```
   팀/투자자 토큰 점진적 출시
   → 갑작스런 공급 증가 방지
   ```

### 가격 안정화 메커니즘

#### 1. Treasury 안정화 펀드

```
Treasury의 20%는 가격 안정화 전용
급격한 가격 하락 시 매수 지원
급격한 가격 상승 시 매도 조정
```

#### 2. 동적 수수료 조정

```

→ API 수수료 (SELA 단위) 하향 조정
→ 사용자 부담 감소

SELA 가격 하락 시:
→ 소각 비율 상향 조정
→ 공급 감소 가속화
```

#### 3. 유동성 인센티브

```

- Uniswap: 5,000 SELA/월
```

## FAQ

### Q1: $SELA는 증권인가요?

**A:** $SELA는 유틸리티 토큰입니다. 플랫폼 서비스 사용을 위한 수단이며, 투자 상품이 아닙니다. 각국의 법률을 준수하며 운영됩니다.

### Q2: 토큰을 어디서 구매할 수 있나요?

**A:** TGE와 동시에 스테이킹 기능이 오픈됩니다.
