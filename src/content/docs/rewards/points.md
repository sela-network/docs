## 개요

### 포인트란?

**Sela Points**는 플랫폼 활동으로 획득할 수 있는 **오프체인 포인트**입니다.

**핵심 특징:**

- 🎁 **무료 획득**: API 사용, 커뮤니티 활동 등으로 획득
- 💱 **토큰 교환**: $SELA 토큰으로 교환 가능
- 🎯 **유틸리티**: 할인, 우선권, 혜택 등에 사용
- ⏰ **시간 가치**: Early Adopter일수록 높은 교환 비율

## 포인트 획득 방법

### 1. 플랫폼 사용 활동

#### API 사용 포인트

**획득 구조:**

```
기본 요청: 1 포인트/요청
VLM 사용: +0.5 포인트
zk-TLS 증명: +0.3 포인트
프리미엄 노드: +0.2 포인트
```

**예시:**

```
일일 API 호출: 100건 (VLM 사용)
일일 획득 포인트: 100 × (1 + 0.5) = 150 포인트
월간 획득: 150 × 30 = 4,500 포인트
```

**누적 보너스:**
| 월간 사용량 | 보너스 배율 |
|------------|-----------|
| < 1,000 요청 | 1.0x |
| 1,000-10,000 | 1.2x |
| 10,000-100,000 | 1.5x |
| 100,000-1,000,000 | 2.0x |
| 1,000,000+ | 3.0x |

#### 프로토콜 기여 포인트

**지출로 획득:**

```
$SELA 지출 1개당 = 10 포인트

예시:
월 API 비용: 100 SELA
획득 포인트: 100 × 10 = 1,000 포인트
```

### 3. Referral (추천) 프로그램

#### 추천 보상 구조

**Tier 시스템:**

```
Tier 1 (직접 추천):
- 피추천인 획득 포인트의 10%를 영구 수령

Tier 2 (간접 추천):
- Tier 1 추천인의 추천인 획득 포인트의 5% 수령

Tier 3 (2차 간접):
- Tier 2 추천인의 추천인 획득 포인트의 2% 수령
```

**예시:**

```
A가 B를 추천 (Tier 1)
B가 C를 추천 (Tier 2)
C가 D를 추천 (Tier 3)

D가 월 1,000 포인트 획득 시:
- C: 기본 1,000 + D의 10% (100) = 1,100 포인트
- B: 기본 + C의 10% (110) + D의 5% (50) = 160 포인트 추가
- A: 기본 + B의 10% + C의 5% (55) + D의 2% (20) = 75 포인트 추가
```

#### 추천 마일스톤

| 추천 인원 | 보너스 포인트 | 추가 혜택                 |
| --------- | ------------- | ------------------------- |

## 포인트 정책

### 유효기간

```
✅ 포인트는 무기한 유효
❌ 만료 없음
⚠️ 단, 12개월 이상 활동이 없으면 휴면 계정 처리
```

### 휴면 계정 정책

```
12개월 무활동 시:
1. 휴면 계정으로 전환
2. 포인트는 유지되나 교환 불가
3. 재활성화: 로그인 + 이메일 인증
```

### 부정 사용 방지

**모니터링 시스템:**

```
❌ 금지 행위:
- 다중 계정 생성
- 봇을 통한 자동 포인트 획득
- 허위 추천
- 스팸 활동

처벌:
1차: 경고 + 해당 포인트 차감
2차: 계정 정지 7일
3차: 영구 정지 + 모든 포인트 몰수
```

### API 통합

**개발자를 위한 Points API:**

```python
from sela_sdk import SelaClient

client = SelaClient(api_key="your_api_key")

# 포인트 조회
points = client.points.get_balance()
print(f"Current points: {points}")

# 포인트 내역
history = client.points.get_history(limit=10)

# 포인트 교환
tx = client.points.exchange_to_token(amount=10000)
print(f"Transaction ID: {tx.id}")
```

## FAQ

### Q1: 포인트는 언제 지급되나요?

**A:** 대부분의 활동은 즉시 지급됩니다. 커뮤니티 기여 등 심사가 필요한 활동은 검토 후 지급됩니다.

### Q2: 포인트를 다른 사용자에게 보낼 수 있나요?

**A:** 아니요, 포인트는 개인 계정에 귀속되며 양도할 수 없습니다. 단, $SELA로 교환 후 자유롭게 전송 가능합니다.

### Q3: 교환 비율은 왜 변하나요?

**A:** Early Adopter에게 더 많은 혜택을 주기 위해 초기 교환 비율이 높습니다. 네트워크 성장에 따라 점진적으로 조정됩니다.

### Q4: 포인트 획득에 상한선이 있나요?

**A:** 획득 자체에는 상한선이 없습니다. 단, $SELA 교환에는 등급별 월간 한도가 있습니다.

### Q5: 포인트가 감소할 수 있나요?

**A:** 부정 행위가 적발된 경우를 제외하고는 감소하지 않습니다. 사용한 포인트는 차감되지만 총 획득 포인트(등급 결정)는 유지됩니다.
