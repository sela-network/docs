## 성능 최적화 권장사항

### 1. 캐싱 활용

```python
# 동일한 URL 반복 요청 시
result = client.browse(
    url="https://example.com",
    options={"cache": {"enabled": True, "ttl": 3600}}
)
# 응답 시간: 1,850ms → 45ms (97% 개선)
```

### 2. 배치 요청

```python
# 여러 URL 한 번에 요청
results = client.browse_batch(urls, max_concurrent=10)
# 처리 시간: 18.5초 → 3.2초 (83% 개선)
```

### 3. 지역 선택

```python
# 타겟 웹사이트와 가까운 지역 노드 선택
result = client.browse(
    url="https://coupang.com",
    options={"region": "kr-seoul"}
)
# 응답 시간: 1,420ms → 680ms (52% 개선)
```

### 4. Lazy Loading

```python
# 필요한 부분만 로딩
result = client.browse(
    url="https://example.com",
    options={
        "wait_for": "domcontentloaded",  # networkidle 대신
        "block_resources": ["image", "media"]
    }
)
# 응답 시간: 1,850ms → 920ms (50% 개선)
```
