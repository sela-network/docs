## 웹의 진화

### 과거의 웹

**인간이 클릭했다.**

```
인간 → 브라우저 → 웹사이트
```

웹은 인간의 눈과 손을 위해 설계되었습니다:

- 시각적 디자인
- 클릭 가능한 버튼
- 읽을 수 있는 텍스트

---

### 현재의 웹

**API가 연결한다.**

```
애플리케이션 → API → 서버
```

프로그래밍 가능한 웹:

- RESTful API
- GraphQL
- SDK 및 라이브러리

**하지만 한계가 있습니다:**

- 모든 웹사이트가 API를 제공하지 않음
- API는 제한적이고 비쌈
- 중앙화된 제공자에게 의존

---

### 미래의 웹

**AI 에이전트가 행동한다.**

```
AI Agent → Sela Network → 모든 웹사이트
```

AI 에이전트가 직접 웹과 인터랙션:

- 거래
- 예약
- 업무 수행
- 의사결정 및 실행

**Sela Network는 이 변화의 핵심입니다.**

---

## Sela Network의 역할

### Layer 0 of AI Economy

Sela Network는 AI 에이전트 경제의 **가장 아래층(Layer 0)**을 담당합니다.

```
┌─────────────────────────────────────┐
│     AI Applications & Services      │ ← Layer 3
├─────────────────────────────────────┤
│      AI Agent Frameworks            │ ← Layer 2
│   (LangChain, AutoGPT, etc.)        │
├─────────────────────────────────────┤
│       AI Models (LLMs, VLMs)        │ ← Layer 1
├─────────────────────────────────────┤
│      Sela Network                   │ ← Layer 0
│  (Web Interaction Layer)            │
├─────────────────────────────────────┤
│         The Internet                │
└─────────────────────────────────────┘
```

### 새로운 운영 계층 (OS Layer)

**인터넷과 AI 에이전트를 연결하는 운영 체제:**

마치 컴퓨터 OS가 하드웨어와 소프트웨어를 연결하듯,
Sela는 웹과 AI를 연결합니다.

| 컴퓨터 OS       | Sela Network     |
| --------------- | ---------------- |
| 하드웨어 추상화 | 웹 복잡성 추상화 |
| 드라이버 제공   | 파서 제공        |
| 시스템 콜       | API 엔드포인트   |
| 프로세스 관리   | 세션 관리        |
| 보안            | zk-TLS 검증      |

## 핵심 가치 제안

### 1. 전 세계 노드가 구동하는 초대규모 분산 브라우저

**세계에서 가장 큰 브라우저 네트워크:**

- 150+ 국가
- 100,000+ 노드
- 초당 수백만 요청 처리
- 글로벌 레이턴시 < 100ms

**기존 솔루션과의 차이:**

| 항목          | 중앙화 솔루션 | Sela Network |
| ------------- | ------------- | ------------ |
| 확장성        | 제한적        | 무한대       |
| 검열 저항성   | 취약          | 강력         |
| SPOF          | 있음          | 없음         |
| 비용          | 높음          | 경쟁력 있음  |
| 지역 커버리지 | 제한적        | 글로벌       |

---

### 2. 모든 웹 데이터의 신뢰성·출처를 증명하는 유일한 프로토콜

**Verifiable Web의 선구자:**

현재 인터넷에서는 데이터의 진위를 증명할 방법이 없습니다.
Sela는 **zk-TLS**를 통해 이를 해결합니다.

**적용 분야:**

#### 금융

```
은행 잔고, 거래 내역, 신용 점수
→ 출처 증명 가능
→ 대출 심사, 금융 감사에 활용
```

#### 법률

```
정부 문서, 규제 공고, 법원 판결문
→ 변조 방지 증명
→ 법적 효력 확보
```

#### 미디어

```
뉴스 기사, 공식 발표, 통계 데이터
→ 원본 출처 확인
→ 가짜 뉴스 방지
```

---

### 3. API가 없는 웹에서도 AI가 자율적으로 행동

**The Long Tail of the Web:**

인터넷의 99%는 API가 없습니다.

**Sela가 열어주는 세계:**

```
API 있는 웹 (1%)
    +
API 없는 웹 (99%)
    =
AI 에이전트가 접근 가능한 100% 웹
```

**실제 활용:**

- 중소기업 웹사이트
- 정부 포털
- 지역 뉴스 사이트
- 소규모 쇼핑몰
- 온라인 도서관

모든 웹사이트가 AI 에이전트의 파트너가 됩니다.

## 장기 비전

### The AI-Native Web

**AI를 위해 설계된 새로운 웹:**

#### 현재 웹

```
HTML/CSS/JavaScript
    ↓
인간의 눈으로 해석
    ↓
마우스와 키보드로 조작
```

#### AI-Native Web

```
Semantic JSON Schema
    ↓
AI가 직접 이해
    ↓
자동화된 액션 실행
    ↓
zk-TLS로 검증
```

**Sela가 만드는 미래:**

- 웹사이트는 AI Agent를 위한 API를 자동으로 제공
- 모든 웹 데이터는 검증 가능
- AI와 인간이 동등하게 웹을 이용
