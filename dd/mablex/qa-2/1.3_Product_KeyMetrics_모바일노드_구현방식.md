모바일 노드 구현 방식

[질문]
모바일 노드 구현 방식 (기술적 구조, PC 노드와의 역할 차이 및 제약 사항 등)

[답변]

모바일 노드는 브라우저 자동화가 아닌 Proxy/VPN 형태로 구현합니다. 플랫폼 제한으로 WebView 기반 자동화는 현실적이지 않으며, 모바일 노드의 핵심 가치는 Cellular IP 제공과 트래픽 중계입니다.

기술 구조:
- PC 노드: 브라우저 자동화
- 모바일 노드: 트래픽 중계

PC vs 모바일 역할 차별화:
- PC 노드: 브라우저 자동화 실행, 복잡한 웹 액션, 인증 세션, 크롤링
- 모바일 노드: 트래픽 중계, Cellular IP 제공

모바일 노드 고유 가치:
- Cellular IP 풀: 모바일 통신사 IP는 Residential IP보다 신뢰도 높음
- 지역 다각화: PC 보급률 낮은 지역에서 노드 확보
- 진입 장벽 완화: 별도 PC 없이 스마트폰만으로 참여 가능

제약 사항:
- 브라우저 자동화 불가 (iOS/Android 모두 브라우저 제어 API 없음)
- 백그라운드 제한 (iOS는 VPN 외 백그라운드 실행 제한)
- App Store 심사 (VPN/Proxy 앱은 심사 기준 엄격)
