# 수집 데이터 메모리 상 처리 기술

## 질문
수집 데이터가 노드 디바이스에 저장되지 않고 메모리 상에서만 처리 관련 기술적 구현 여부

## 답변

노드는 데이터를 저장하는 로직이 없으며, 아키텍처 구조상 저장이 불필요합니다.

통신 구조:
- Client → Agent Node: libp2p 기반 P2P 프로토콜로 통신
- Agent Node → Browser: CDP(Chrome DevTools Protocol)로 로컬 브라우저 제어

저장 로직이 없는 이유:
- Agent Node는 클라이언트의 요청을 받아 로컬 브라우저를 제어하고, 결과를 실시간 스트리밍 방식으로 클라이언트에 전달합니다.
- 데이터가 노드에 머무르지 않고 즉시 전달되는 구조이므로, 파일이나 스토리지를 사용할 필요가 없습니다.
- 모든 데이터는 메모리 상에서만 처리되며, 세션 종료 시 자동으로 휘발됩니다.
