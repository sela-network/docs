토큰 유틸리티

[질문]
SPWR 포인트와 $SELA 토큰의 유틸리티는 각각 무엇인가요?

[답변]

Sela 생태계는 포인트-토큰 이원 구조로 운영되며, 각각 명확히 분리된 역할을 수행합니다.

1. SPWR 포인트 (노드 보상 + 거버넌스)

  (1) 노드 보상
    - 노드 운영자가 작업 수행 시 SPWR 포인트로 보상 지급
    - 응답률에 따른 등급별 차등 보상 (Gold/Silver/Bronze)

  (2) 스테이킹
    - 노드 참여 시 SPWR 포인트를 보증금으로 예치
    - 노드 운영으로 획득한 SPWR 포인트 활용 가능 (낮은 진입 장벽)

  (3) 거버넌스 참여
    - 프로토콜 파라미터, 보상 정책, 생태계 인센티브 등 핵심 항목에 대한 투표권
    - 주요 기능 및 파트너십 방향에 대한 제안 권한


2. $SELA 토큰 (유틸리티)

  (1) AI Agent 마켓플레이스 결제
    - 에이전트 거래, 수수료, 프리미엄 기능 접근 등 마켓 내 경제 활동
    - B2B/B2C 서비스 결제 수단

  (2) Web Access Data 구매
    - API 기반 데이터 이용료 결제
    - 사용량 기반 과금, 크레딧 모델 등 데이터 제품 매출과 연결

  (3) SPWR ↔ $SELA 스왑
    - TGE 이후 SPWR 포인트를 $SELA 토큰으로 스왑 가능
    - 노드 운영자가 $SELA 유틸리티에 접근할 수 있는 경로 제공


3. 이원 구조의 의의

  - 역할 분리: 노드 생태계(SPWR 포인트)와 서비스 생태계($SELA 토큰)의 명확한 구분
  - 가치 연결: 스왑 메커니즘을 통해 두 생태계 간 가치 흐름 연결
  - 확장성: 각각의 유틸리티를 독립적으로 확장 가능
