$SELA 바이백/소각 메커니즘

[질문]
$SELA 토큰 바이백 또는 소각 메커니즘 도입 여부 및 진행 방식(주기, 규모 등)은 어떻게 되나요?

[답변]

1. 기본 방향

$SELA 토큰 직접 결제 대신, Fiat/스테이블코인 실매출 기반 바이백 소각 구조를 적용합니다. 가격 방어 목적이 아닌, 실제 매출과 토큰 가치를 직접 연동하는 설계입니다.

  (1) 구조
    - 고객은 Fiat/스테이블코인으로 서비스 결제
    - 매출의 일정 비율로 시장에서 $SELA 바이백 후 소각
    - 실매출 증가 → 바이백 증가 → 토큰 공급 감소 → 가치 상승

  (2) 장점
    - 실질적인 Fiat 매출 확보 (명확한 비즈니스 검증)
    - 토큰 매도 압력 없음 (운영비를 위한 토큰 판매 불필요)
    - 매출과 토큰 가치의 직접적 연동


2. 바이백 재원

Fiat/스테이블코인 매출이 발생하는 모든 서비스에서 재원을 확보합니다.

  - GrowlOps: B2B 구독료, 캠페인 운영비
  - AI Agent 마켓플레이스: 에이전트 거래 수수료
  - Web Access Data: API 이용료, 사용량 기반 과금


3. 운영 방식

  - 방식: 정기 바이백 후 소각
  - 주기: 월간 또는 분기 단위 정산
  - 비율: 매출의 일정 비율 (구체 비율은 매출 구조 확정 후 결정)
  - 거버넌스: 비율 및 시행 시점은 SPWR 포인트 홀더 투표로 최종 확정


4. SPWR 포인트 소각

$SELA 바이백 소각 외에, 슬래싱된 SPWR 포인트도 전량 소각 처리되어 디플레이션 효과를 강화합니다.
