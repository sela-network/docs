유저 및 기업 고객 확보 전략

[질문]
일반 유저(노드 오퍼레이터) 및 기업 고객 확보 전략

[답변]


1. 노드 확대 전략

  (1) 노드운영자 친화적 Product
    - 간편하고 쉽게 노드 설치/운영 가능
    - 투명하고 신뢰할 수 있도록 유저 customizable 노드앱 고도화

  (2) BM 연동 노드확대 선순환
    - Point earn 기반 노드 확대
    - Sela Network 커버 가능한 플랫폼 확대
    - 매출 증가 → 노드 운영자 benefit 확대 → 노드 확대

  (3) 파트너십을 통한 노드 제공자 확대
    - GrowlOps, 프로젝트 Chatbot 도입 프로젝트 파트너 유저 대상
    - Sela 노드 운영 시 benefit 제공 프로모션

  (4) 노드 Referral 프로그램
    - 노드 운영자 코드를 통해 추천인 benefit 제공


2. 기업 고객 확보 전략

  (1) Pain Point 기반 타겟팅
    - X, LinkedIn, Medium, 중국계 SNS 등 특수 private data 접근 필요 기업
    - AI agent 회사, 마케팅회사, 리서치 회사에게 pain killer로서 API 제공

  (2) Vertical SI 협업
    - AI agent를 만들어 공급하는 Vertical SI 업체들과 협업
    - Vertical 시장 공략

  (3) 빌더 커뮤니티 침투
    - AI agent builder, Solo AI agent builder 커뮤니티 침투
    - Sela API 인지도 제고

  (4) 해커톤 개최
    - 대형 AI 관련 회사 및 프로젝트와 함께 해커톤 개최
    - Sela API credit 제공으로 빌더 커뮤니티 침투

  (5) 플랫폼 파트너십
    - AI agent 툴 플랫폼, 마켓플레이스와 파트너십 기반 기업 타겟 접근


3. Web2 기업 타겟 전략 (미국 및 서구권)

  (1) 목표
    - 참여 지표 확대보다 Web2 기업 대상 실사용 기반 확장
    - 노드 전환 촉진

  (2) 실행 방안
    - Web Access Data API 세일즈 접근 중심
    - 데이터 커버리지 확대 및 안정성 강화 소식 주간 업데이트
    - 기업/빌더 대상 빌드 사례, 파트너십, 제품 업데이트 정기 발신
    - 리드 생성 및 파이프라인 구축 고도화

  (3) 콘텐츠 고도화
    - 유스케이스, 데모, 성능/커버리지 리포트, 통합 가이드 제공
    - 도입 장벽 최소화
    - 도입 파트너의 사용자 기반을 노드 확대로 연결

  (4) 내러티브
    - "노드가 AI agent로 작동하며 자동화된 실행 주체가 된다"
    - B2B 유스케이스와 결합해 가치 인식 강화
