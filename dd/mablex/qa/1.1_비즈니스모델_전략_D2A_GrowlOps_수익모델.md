1. Browse API (D2A / Web Access API)

  AI agent 사업자, 버티컬 AI agent 빌더, 기타 데이터접근이 필요한 기업 대상 web access API 제공

  (1) Researcher (Free)
    - 월 1,000 API credits 무료 제공
    - 신용카드 등록 불필요
    - 이메일 서포트
    - 목적: 개발자/리서처 온보딩, 제품 체험

  (2) Pay As You Go
    - $0.0064 / credit
    - 사용한 만큼만 결제
    - 이메일 서포트, 언제든 취소 가능
    - Production-grade API keys
    - 종량제 청구 (Billed incrementally)
    - 목적: 유동적 사용량, 초기 스타트업

  (3) Monthly Plans (구독형)
    - Project: 4,000 cr/mo, $24/mo ($0.006/cr)
    - Bootstrap: 15,000 cr/mo, $80/mo ($0.0053/cr)
    - Startup: 38,000 cr/mo, $176/mo ($0.0046/cr)
    - Growth: 100,000 cr/mo, $400/mo ($0.004/cr)
    - Pay as you go 모드: 초과 사용 시 기본 요금($0.0064/cr)으로 자동 과금
    - Auto upgrade 모드: 사용량 초과 시 자동으로 상위 플랜으로 업그레이드
    - 목적: 예측 가능한 비용 관리, 볼륨 디스카운트 혜택

  (4) Enterprise (Custom)
    - 볼륨 디스카운트
    - Custom rate limits
    - Enterprise-Grade support & SLAs
    - Custom Single Sign-On (SSO)
    - MSA & DPA 지원
    - 전용 Slack 채널, 아키텍처 가이던스 제공
    - 목적: 대기업, 고볼륨 사용자


2. API Credits Breakdown

  (1) Browse Search
    - Basic search: 1 credit / query
    - Advanced search: 2 credits / query

  (2) Browse Extract
    - Basic extract: 1 credit / 5 URLs
    - Advanced extract: 2 credits / 5 URLs

  (3) Browse Map
    - Basic map: 1 credit / 10 URLs
    - With instructions: 1 credit / 5 URLs

  (4) Browse Crawl
    - Map pricing + Extract pricing

4. GrowlOps (소셜 캠페인 X 마인드쉐어 Analytics)

  프로젝트/마케팅 팀이 커뮤니티/캠페인을 "실행→측정→최적화"하도록 하는 운영툴(Ops) 제공

  (1) 초기 단계
    - 무료 제공 + 파트너십 및 코마케팅

  (2) 구독 형태
    - 월단위 추적 키워드, 포스트 수 종량제, 검색 키워드 수에 따른 과금
    - Standard $3,000/m: Workspace 1, Keywords upto 10, Posts upto 30k posts/month, 90 days data retention
    - 캠페인 수, 데이터 보존기간에 따른 별도 티어 운영

  (3) Usage 기반
    - 이벤트/캠페인 추적량, 대시보드 갱신 빈도, 분석 리포트 생성량 등에 따라 과금
