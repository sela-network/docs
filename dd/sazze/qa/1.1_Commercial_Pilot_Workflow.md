# Pilot Workflow on Sela Network

## 질문
For your current pilots, can you walk us through the workflow they run on Sela Network?

## 답변

현재 파일럿 고객은 크게 두 가지 워크플로우를 실행합니다.

Browse API 워크플로우:
- Linqalpha: 금융 데이터 웹 크롤링 → AI 종목 리포트 생성
- Sapiens: 뉴스/소셜 데이터 수집 → AI Agent 기반 미디어 콘텐츠 생성
- Upflux: B2B 잠재 고객 웹 데이터 수집 → 리드 제네레이션 자동화
- Quack AI: 온체인/오프체인 데이터 수집 → AI Agent 위임 기반 거버넌스

GrowlOps 워크플로우:
- 소셜 캠페인 설정 → 키워드/해시태그 트래킹 → 마인드쉐어 분석 → 캠페인 최적화
- 현재 Nebula, Nad.fun 캠페인 진행 중, 8개 프로젝트 온보딩 중

공통 패턴: API 호출 → 분산 노드에서 웹 액션 실행 → 구조화된 데이터 반환 → 고객 서비스에 통합
