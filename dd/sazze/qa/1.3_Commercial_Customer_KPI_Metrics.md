# Customer KPI/Metrics for Renewal

## 질문
What internal KPI or metric does that customer use to justify renewal or expansion?

## 답변

고객 유형별 갱신/확장 판단 KPI:

Browse API 고객:
- API 성공률: 요청 대비 성공적 데이터 반환 비율 (목표: 99.99%+)
- 비용 효율: 기존 솔루션 대비 크레딧당 비용 절감
- 처리량: 일/월간 처리 가능한 요청 수
- 데이터 품질: 추출 데이터의 정확도 및 완전성

GrowlOps 고객:
- 마인드쉐어 성장: 캠페인 전후 소셜 언급량/도달률 변화
- 팔로워 증가율: 캠페인 기간 내 팔로워 순증 (자체 캠페인에서 35.8% 증가 검증)
- 콘텐츠 성과: 포스트당 조회수, 좋아요, 리포스트
- ROI: 캠페인 비용 대비 도달/전환 효율

공통: 운영 시간 절감 (자동화로 인한 수동 작업 감소)
